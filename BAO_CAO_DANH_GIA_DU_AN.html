⚠️ 3. Vấn đề cần khắc phục

🔴 CRITICAL - Accessibility Issues Critical

1. Thiếu ARIA labels cho interactive elements

Vấn đề: Buttons, inputs, selects không có aria-label. Screen reader users sẽ khó sử dụng.

Fix: Thêm aria-label cho tất cả controls

2. Contrast ratio chưa đạt WCAG AA standard

Vấn đề: Text màu #94a3b8 trên background #2c3e5a có contrast ratio ~3.5:1 (cần ≥4.5:1)

Fix: Tăng độ sáng của text-secondary lên #a8b8d0

3. Keyboard navigation chưa hoàn chỉnh

Vấn đề: Focus states không rõ ràng, tab order chưa logic trong tables

Fix: Thêm visible focus outline và cải thiện tabIndex

🟠 HIGH PRIORITY - UX Usability Issues High

4. Search trong Sidebar không hoạt động

Location: src/components/Sidebar.jsx line 25

Vấn đề: Input không có onChange handler

Fix: Implement search functionality hoặc ẩn đi

5. Form validation messages chưa i18n

Vấn đề: Hard-coded Vietnamese messages, khó maintain

Fix: Tạo src/i18n/messages.js cho centralized messages

6. Loading states không consistent

Vấn đề: Một số API calls có spinner, một số không

Fix: Đảm bảo tất cả async operations có loading indicator

7. Empty states chưa rõ ràng

Vấn đề: Khi không có dữ liệu, bảng chỉ hiển thị trống

Fix: Thêm empty state với icon + message hướng dẫn

🟡 MEDIUM PRIORITY - Technical Debt Medium

8. Mock data quá lớn trong single file

mockAPICongNo.js có 1195 dòng

Fix: Tách thành mockData/suppliers.js, mockData/customers.js

9. CSS duplication across components

Fix: Extract shared styles vào src/styles/shared.css

10. Không có error boundary

Vấn đề: Khi component crash, toàn bộ app sẽ white screen

Fix: Thêm React Error Boundary wrapper

11. Date formatting không consistent

Fix: Tạo utility function formatDate() trong src/utils/dateHelpers.js

12. Missing PropTypes validation

Fix: Thêm PropTypes hoặc convert sang TypeScript
